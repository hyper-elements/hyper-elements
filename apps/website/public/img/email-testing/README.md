# Email playground assets

These assets are served locally so the default example and client labels also work on preview deployments.

- `macbook-air.jpg`: [Apple Newsroom, MacBook Air press images (March 5, 2025)](https://www.apple.com/newsroom/2025/03/apple-introduces-the-new-macbook-air-with-the-m4-chip-and-a-sky-blue-color/), the 980 × 551 hero image. Copyright Apple. Used in a labeled concept email with original sample copy.
- `gmail.svg`: `google-gmail-2020` from [SVG Logos](https://github.com/gilbarbara/logos), via [Iconify's collection](https://github.com/iconify/icon-sets/blob/master/json/logos.json), CC0-1.0.
- `outlook.svg` and `aol.svg`: [Simple Icons 11.0.0](https://github.com/simple-icons/simple-icons/tree/11.0.0), CC0-1.0. Outlook uses its blue brand color; AOL's view box is cropped to the wordmark.
- `yahoo.svg`: compact lettermark adapted from SVG Logos' Yahoo wordmark, CC0-1.0.
- `apple-mail.svg`: a small envelope icon drawn for the client label, using Mail's familiar blue background.

Client logos identify the products being previewed. They are decorative beside their text labels.
